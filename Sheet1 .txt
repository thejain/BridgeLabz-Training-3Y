3.Describe how a browser requests and displays a web page from a web server.


When a visitor types a URL into their browser, the client and web server utilize the HTTP/HTTPS protocol to communicate and render the requested page.
The Interaction Lifecycle
1. URL Entry:
   * The visitor enters a domain (e.g., www.example.com) in the address bar and hits Enter.
2. DNS Translation:
   * The browser queries the Domain Name System (DNS) to resolve the human-readable domain into the server's IP address.
3. HTTP/HTTPS Request Initiation:
   * Using the IP, the browser triggers an HTTP/HTTPS request to the web server to fetch the page contents.
4. Server-Side Execution:
   * The web server receives and processes the request, gathering necessary files and database data to compile a response.
5. Resource Delivery:
   * A response is sent back via HTTP response, containing HTML, CSS, JavaScript, and asset files.
6. Client Rendering:
   * The browser parses the HTML, executes scripts, and applies styles to visually present the website to the user.

	5. Explain what a web server is and give examples of commonly used servers.
A web server is software (and sometimes the computer running it) that stores, processes, and delivers web pages to users over the Internet using the HTTP or HTTPS protocol. It receives requests from web browsers, processes them, and sends back the requested web pages, images, videos, or other resources.
How a Web Server Works
1. A user enters a website URL in a web browser.
2. The browser sends an HTTP/HTTPS request to the web server.
3. The web server processes the request and retrieves the required files or data.
4. The server sends an HTTP response containing the requested webpage.
5. The browser displays the webpage to the user.
Web Server
	Purpose
	Apache HTTP Server
	One of the most popular open-source web servers. It supports multiple operating systems and is widely used for hosting websites and web applications.
	Nginx (Engine-X)
	A high-performance web server known for handling many simultaneous connections. It is commonly used as a web server, reverse proxy, and load balancer.
	Microsoft Internet Information Services (IIS)
	A web server developed by Microsoft for Windows-based systems. It integrates well with ASP.NET applications.
	LiteSpeed Web Server
	A high-speed commercial web server compatible with Apache. It offers improved performance and security for busy websites.
	Apache Tomcat
	A Java-based web server and servlet container used to deploy Java web applications.

8.Explain the difference between static and dynamic websites. Provide an example of each.
Static Website
A static website is a website whose content remains the same for every visitor. The web pages are created using HTML, CSS, and JavaScript, and they are delivered exactly as stored on the server. Any changes to the website must be made manually by editing the source code.
Characteristics:
* Displays fixed content to all users.
* Does not require a database.
* Loads faster because pages are pre-built.
* Easy to develop and host.
* Suitable for small websites with limited content.
Example:
 A personal portfolio website, college information website, or company brochure website, where the information rarely changes.
________________


Dynamic Website
A dynamic website is a website whose content changes based on user requests, database information, or server-side processing. It uses server-side programming languages and databases to generate web pages dynamically.
Characteristics:
* Displays different content for different users.
* Uses a database to store and retrieve information.
* Supports user interaction such as login, registration, search, and online shopping.
* Content can be updated without changing the website's source code.
* Suitable for large and interactive web applications.
Example:
 An Amazon or Flipkart shopping website, where users can log in, search for products, view personalized recommendations, and place orders.

How Rendering Engines Differ
1. Blink
* Used by Google Chrome, Microsoft Edge, and Opera.
* Fast rendering and high performance.
* Excellent support for modern web technologies.
* Frequently updated through the Chromium project.
2. Gecko
* Used by Mozilla Firefox.
* Open-source rendering engine focused on web standards and user privacy.
* Developed independently by Mozilla.
* Optimized for security and standards compliance.
3. WebKit
* Used by Apple Safari.
* Optimized for Apple devices.
* Consumes less power, improving battery life.
* Provides smooth performance on macOS and iOS.
